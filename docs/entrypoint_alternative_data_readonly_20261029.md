# 回测和实盘出单只读已发布另类数据

直接运行 `strategy/bt_execution.py` 或 `strategy/generate_trade_orders.py` 时，此前若 `reduction_records.pkl` 等缓存超过 24 小时，或减持计划最后公告日早于今天，组合构建阶段会触发 `AlternativeDataProvider` 的隐式联网刷新。这可能在一次回测或当日出单中修改历史数据和输入指纹，并绕过 `data/refresh_all.sh` 的刷新验证。

现在两个主程序在导入 `core` 之前强制设置 `QUANT_ALT_NO_AUTOREFRESH=1`；数据仅由生产刷新脚本显式抓取，然后由回测和出单读取。封存研究运行原已设置该变量。单测执行两个真正的主程序导入前缀，强制将外部环境设为 0 并检查加载策略/配置模块之前变量已改为 1，因此显式错误配置也不能重新打开隐式下载。

只读模式下缺失龙虎榜、两融、北向、减持、解禁或业绩预告源缓存时，提供者现在直接报错，不再偷偷下载或新建缓存；缺龙虎榜历史明细同样报错。已启用的减持记录/计划过滤器不能再把缺文件或读取失败转成空股票集。三组隔离测试覆盖所有缺源入口、组合硬闸和陈旧缓存只读读取。此变更不修改已有数据；完整生产链及收益回测尚待验证。
