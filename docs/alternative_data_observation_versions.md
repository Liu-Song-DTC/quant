# 另类数据的观测版本（2026-10-30）

刷新接口不是不可变事件日志：减持公告会迟到，北向历史数值会重述，近一年龙虎榜是滚动聚合快照。仅按记录中的公告日期过滤，不能保证刷新后历史决策不变。

生产刷新在 `data/refresh_altdata_0902.py` 将 `reduction_records`、`reduction_plans`、`margin_daily`、`northbound_daily`、`dragon_tiger_history`、`dragon_tiger` 的每次观测存成内容寻址快照；原文件仍供实盘读取。历史查询通过 `strategy/core/alt_data_versions.py` 取不晚于决策日的最近观测版本，保留迟到记录的实际到达时间。刷新校验 `data/verify_alt_observations.py` 检查当前文件与版本清单一致，以及首版与末版的归档完整。生产信号和出单阶段禁止自动重新下载另类数据，缺版本即停。封存回测也把版本清单及归档纳入数据指纹。

首次实际观测：2026-10-29 23:09 的刷新前封存；第二次观测：2026-10-30 06:08 的刷新后封存。仅有日期级记录，不能据此推断盘中精确可用时刻。**2026-10-29 之前的回测使用固定首版作历史代理，并不证明当时真的看得到全部旧记录。**龙虎榜滚动聚合不存在可用的历史明细买卖额，首次观测之前拒绝代理；当前策略配置仍关闭该个股信号。解禁数据沿用已有 `unlock_schedule_versions.json` 的同类版本合约；业绩预告和两融个股明细目前不参与生产策略，若重新启用需单独审计/版本化。

此次刷新独立核对结果：概念行情旧交易日无变化，原概念名单的 14 个日期版本未被改写，仅追加 2026-10-30 一版。当前概念名单中的 1,547 只股票归属变化，但历史因子和概念热度查询仍按日期版本取值。新增的九条减持记录中，两条公告时间为 2026-10-28：新版过滤会在 2026-10-30 起看见它们，旧历史决策继续使用刷新前观测版本。

如果别的机器仅同步代码而未同步版本归档，生产信号会拒绝缺失的版本。可在新机用已有历史归档恢复，或者将当前文件作为**新的首版历史代理**明确登记，不能伪称它是历史上各日实际观察的数据。研究封存快照不使用当前机器上不断变化的 live 数据目录。
