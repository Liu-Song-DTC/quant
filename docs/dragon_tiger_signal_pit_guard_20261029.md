# 龙虎榜日期解析失败的时点边界

`AlternativeDataProvider.get_dragon_tiger_signal()` 原先只要龙虎榜汇总表含一条无法解析的日期，整列 `pd.to_datetime()` 就抛异常，随后把 `date_mask` 设为全真。历史查询因此可能读到决策日之后的上榜记录。`get_dragon_tiger_dates()` 的历史集合和汇总回退也在查询日无效时可能返回未按日过滤的集合。

现在逐条将无法解析的源日期转为 `NaT`，日期比较自然剔除这些行；无效查询日直接返回中性信号或空集合。正常日期、正常源数据的评分公式不变。隔离样例同时放入过去、未来和非法上榜日，验证历史日期只读取当时已发生的记录。实际生产文件暂未发现日期解析失败事件，因此本补丁不是已证实的历史 NAV 改善，更不能以单测代替真实公告发布时间校验。
