## 持仓跨越公司行为的执行风险盘点

运行 `strategy/analysis/audit_held_corporate_actions.py`，输入刷新后封存 run 的
`execution_fills.csv` 和**同一 run** 的 `events_table.pkl`，按除权日开盘前
的模拟持仓识别公司行为；输出为本地
`.review_runs/data_post_refresh_20261029/held_corporate_actions.json/.csv`。
21 个持仓跨越事件涉及 19 只股票；21 个都来自 `em`，其 `s`、`D`
字段齐全，其中 3 个事件有送转。这个结果只说明上述样本有可查的事件参数，
**不能**把 QFQ 模拟股数乘以 `D` 当作真实到账现金，也不能推断公司行为
实际入账时间。测试覆盖除权日开盘卖出仍享有前收盘权益、当日开盘新买不享有
前收盘权益、字段缺失的识别以及非法负持仓拒收。

下一个有意义的收益实验：封存选股信号不变，以裸开盘价和真实整手计算交易，
按真实持仓处理这 21 个公司行为并用裸收盘价估值；逐笔对齐 QFQ 基线的
交易意图及现金流，比较净值、短期胜率、最大回撤和差异归因。未经完整
公司行为记账的直接“裸价替换”会丢失分红和送转收益，不能作为策略改善
或退化的证据。

后续通过 `strategy/analysis/review_validation.py` 完成的封存全量回测，在校验
输入快照未变并归档成交后，会自动运行裸价整手与持仓跨事件两项只读审计，
把报告和脚本 SHA-256 记入该 run 的归档/清单；若审计失败则明确报错，
不会把缺失的执行核验当作完成。该钩子只影响**未来由新版脚本发起**
的运行；本次已完成的封存回测审计报告由独立命令生成。

现有 21 次持仓事件的登记日侧车原存于被快照隐藏目录排除的
`.ca_record_parts/`。新版 `review_validation.py` 只纳入该目录的
5,128 个登记日侧车（当前约 3.5MB），仍排除其他抓取临时缓存，
保证**未来**封存 run 可按同一字节输入回查登记日。旧 PRE/POST
封存未包含这些文件，事后用当前侧车得到的 `21/21` 覆盖率只是
独立来源核验，不能冒充旧封存当时已持有对应登记日。与现有
`docs/action_terms_issuer_verified_20261029.csv` 对照，发行人公告
完整核实权益与日期的截至 2026-10-30 为 4/21，仍有 17 条需要继续补证。

## 2026-10-31：全市场封存 QFQ 算术与精度检查

用同一封存快照对全部 5,350 个具备裸价的股票文件执行
`audit_qfq_events.py`，本地结果为
`.review_runs/data_post_refresh_20261029/qfq_full_market_audit_20261031.json`。
37,345 个公司行为日、11,005,978 个普通交易日的复权价格收益，
与原价及封存事件表在**两位小数的理论舍入误差界内**一致：
`exception_count=0`，普通日超界 0；另外 3 个缺裸价的文件是指数
`399006`、`sh000001`、`sh000852`，不计作有裸价股票。
这个审计核对内部算术，不能确认上游分红送转条款、公司行为完整性或
实盘裸价买卖的现金/持股账本。

精度边界仍值得单独研究：2021 年以后，6,855,577 个普通交易日中，
35 个按两位小数 QFQ 收盘计算的日收益与裸价日收益差超过 1 个百分点，
但均未超出对应价格（通常很低）的舍入界；例如 600734 在
2021-02-05 的差约 2.03 个百分点，前一日复权收盘仅 0.43 元。
当前封存 run 的 161 条入选和 2,343 笔成交对应的收盘 QFQ 均不低于
1 元，未直接遇到这一低价位精度问题；全股票池因子、动态 IC 是否
受间接影响尚需另行检验。若实验更高精度 QFQ，必须隔离分支并重跑
全链回测，不能直接改生产历史文件，否则会同时改变输入指纹、信号和
100 股手数取整口径。
