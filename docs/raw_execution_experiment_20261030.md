# 裸价成交回放：数据契约与实验门槛

现行向量化回测在 `strategy/bt_execution.py::_vectorized_backtest` 中把
自算 QFQ 开/收盘价用于股数取整、现金、持仓市值和收益。对应的实盘
下单读取裸价。2026-10-28 截止封存样本有 387 笔买入；按相同名义
金额换算成裸价整百股，301 笔股数不同，66 笔加仓金额低于一手裸价。
这只是成交模型的可行性诊断，不能把名义金额差直接加减到原回测净值。

实验须保持同一份已封存信号/选股决定，另外构造独立的裸价执行与估值
分支。开盘按裸价确定交易股数，保留现金不足、涨跌停、T+1、停牌、
最小交易单位和既有滑点/费用约束，收盘按裸价估值；股权登记日收盘
的真实持仓决定权益归属，除权日处理股份变化，现金红利在**明确的
到账日**成为可再投资现金，提前只记应收。组合权重或信号若依赖现有
QFQ 成交反馈，需在两臂中按各自真实模拟净值重新计算，不能在
不同现金/股数状态下复用另一臂的成交记录。

本地 `events_table.pkl` 只有 `ex_date, s, D, mult, src`，没有现金
发放日、新股可流通日及税费记账；`corporate_actions.pkl` 同样只有
`code, ex_date, s, D`。仓位跨越的 21 次事件中，3 次涉及送转；
当前 21 条事件表 `s,D` 均非缺失。现有的登记日侧车经
`audit_action_record_coverage.py` 核验 **21/21** 有来源记录，但此前
它们存于隐藏目录，未进入封存数据指纹；已修复以后封存会复制并哈希
这些侧车，旧 run 不可追溯地套用后刷新的侧车来声称 PIT。

既有 `docs/action_terms_issuer_verified_20261029.csv` 通过
`audit_issuer_settlement_terms.py` 核验发行人公告 **4/21**（其中
2 次送转）；另 **17 次**只具备供应商条款，仍须逐一查实施公告并
封存登记、除权、红利发放、新股可交易日期和差异化分配条款。
对应的审计说明在 `docs/action_record_date_sidecar_20261029.md`。
缺任何关键字段的持仓事件都不得静默假设当天到账。

当前本地事件表不含红利到账日，不能把 `ex_date` 字段假定为可用现金日；
实施公告中的具体日期和差异化条款须独立核验并随实验封存。

先以现金分红、送转、无公司行为三只股票构造可手工对账的回放样例，
检验除权日前后 `现金 + 应收 + 裸股数 × 裸价` 与 QFQ 价格财富变化
的关系；再上全池同信号的成本净值成对实验，输出逐日权益、买卖差异、
真实整手不可成交次数、1/3/5 日胜率、2026 年回撤和完整年度指标。
税费及同日到账无法证实前不得用该分支声称“实盘收益已经证明提高”。

## 发行人权益记账只读探针（2026-10-30）

`probe_issuer_entitlements.py` 先与 2026-10-29 封存持仓事件做公告条款对照，
然后**仅假定登记日收盘真实持有 100 股裸价股票**，分别算送转股和应收股息：
300580 得 50 股、40 元；300953 得 40 股、30 元；603444 得 700 元；
600858 得 2 元。输出在
`.review_runs/data_post_refresh_20261029/issuer_entitlement_probe_100shares_20261030.csv`。
`cash_available_before_open` 与 `cash_dividend_tax` 明确为 `UNKNOWN`，
不把公告的现金发放日期等同于开盘可用现金；不足整数股的新股权益直接
报错，等待发行人和券商的零碎股处理规则。100 股只是算术测试，不是
2026-10-29 封存回测的历史真实仓位；当时 QFQ 股数不能转换为实际持股。

```bash
.venv/bin/python -B strategy/analysis/probe_issuer_entitlements.py \
  --held .review_runs/data_post_refresh_20261029/action_record_coverage_current_sidecars.csv \
  --issuer docs/action_terms_issuer_verified_20261029.csv \
  --shares-on-record 100 \
  --out .review_runs/data_post_refresh_20261029/issuer_entitlement_probe_100shares_20261030.csv
```

其余 17 次持仓事件和 300416 的送转公告尚需独立校核。真实裸价实验下一步
必须重放全量逐日买卖，计算每个登记日收盘裸股数，按券商实际结算可用时点
和税费记账，再成对比较两臂净值；目前没有得出修正后的收益结论。

## 原价执行首轮机制核验（2026-10-31）

`strategy/core/raw_corporate_action_ledger.py` 已建立**独立研究原型**，按
原价记现金和交易股数，并分别记录应收现金及尚不可卖的送转股。
`cash_available_date` 必须独立输入；发行人现金发放日不能直接推断为
开盘可再投资日期。`strategy/core/raw_execution_prices.py` 严格读取
`raw_data/{code}/none.csv` 的开高低收；停牌日保持缺价、重复日及异常
OHLC 拒绝，不使用 QFQ 开盘价伪造成交。

在 `alt_preobs_proxy_20261031` 相同封存数据上，2,343 笔模拟成交涉及
151 只股票，逐笔成交日原始开盘价均可读取（0 个缺价或异常）；这只检查
**现有模拟成交**的原价可用性，不保证新执行臂改变的交易也全部有原价。
`probe_raw_wealth_bridge.py` 用已核对的四份发行人公告，分别假定登记日
收盘持有真实 100 股，核对除权日收盘的
`现金 + 应收股息 +（可交易股 + 待上市送转股）× 原价` 与 QFQ
记录日至除权日收益；四条最大绝对差为 **0.04698 个百分点**，仅代表
此两日财富桥接与价格舍入一致，不表示已重放组合净值、税、券商可用时点。
输出为 `.review_runs/alt_preobs_proxy_20261031/raw_wealth_bridge_issuer4.csv`。

原价执行尚未接入 `bt_execution.py` 主循环；17/21 次持仓事件缺发行人
核实的到账／可交易条款。下一步需从封存的原价 OHLC 构造独立执行矩阵，
保留 QFQ 仅供信号与可比收益；按登记日收盘仓位记权益、在除权日分开
处理股数和应收股息，再以确认的现金可用时点入交易现金。未核实条款
必须在新研究臂中明确阻断并记录，不能静默把 QFQ 收益当真实成交净值。

### 主循环隔离接线（研究开关，仍禁止完整收益外推）

`QUANT_RAW_EXECUTION=1` 只在向量化执行层切换到原价开盘、最低、
收盘价；信号输入继续为 QFQ，涨跌停／跳空的跨除权判据仍用 QFQ
收益比，避免把除权造成的裸价落差误判为跌停。原价收盘缺失时只
用已有最后真实收盘**估值**，绝不用此前开盘伪造成交。当前尚未把
发行人现金／股数账本接入主循环：任何持仓跨越融合事件表的除权日
都会直接抛错并停止研究臂，禁止产出伪造的“全期原价收益”。

`test_review_regressions.ExecutionTests` 的无事件微型执行验证
按原价 100 股取整、除权日买入不因未经调整的假跌停被拦截，
而跨未核实的持仓事件会中止；原默认执行回归也仍通过。
这是**研究臂接线阶段**，不是生产默认变化，更没有全量配对 NAV。
后续需用发行人公告补齐 17 个持仓事件与原价账本，实现真实股数／
应收／可用现金一致后，才能解除持仓事件门禁并做完整回测。

### 封存事件证据清单与原价缺价门禁（2026-10-31）

在 `.review_runs/alt_preobs_proxy_20261031` 的封存成交、事件表与登记日
侧车上重新运行 `audit_action_record_coverage.py`：161 笔完整交易中，
20 笔交易跨越共 21 次公司行动；21/21 有供应商登记日和现金／送转拆分，
但仅 4/21 已有发行人实施公告核验。待核的 17 次（其中 300416
2023-05-19 涉及送转）列在同一封存目录的
`raw_action_issuer_evidence_queue.csv`，含代码、持仓区间、登记日、除权日、
供应商权益条款与公告核验状态。这份清单不是公告核验，也不证明券商开盘可用
现金日期。**实验分支仍阻断跨越未完整记账的持仓事件，不声称已有原价全期收益。**

原价研究开关另要求：QFQ 有成交的交易日若缺裸价收盘，该股票不能进入当日
选股池；若当天有成交量且已持仓，则停止回测并报缺价错误。停牌且没有
成交量时仍可用最后真实收盘估值，但绝不补造可执行的开盘。对应无原价
选股、活跃日缺价拒绝及原默认路径测试均已覆盖。

`strategy/analysis/probe_raw_held_price_coverage.py` 可对封存 run 的历史已持仓
区间重新核对 QFQ 有成交日与原价收盘价是否配对。执行
`--run .review_runs/alt_preobs_proxy_20261031` 得到 151 个已交易代码、
4,542 个活跃持仓日、0 个原价缺口和 0 个原价 OHLC 校验失败，审计
输出在 `raw_held_price_coverage.json`。该验证只证明旧交易轨迹的价格
覆盖，不对尚未运行的原价执行臂预测将来持仓的覆盖率。
