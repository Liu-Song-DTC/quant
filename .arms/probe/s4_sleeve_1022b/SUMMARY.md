# S4 独立 sleeve 探针 — 买点源级轴最后一种收割形式 (10/22)

**结论: 拒绝。S4 独立 sleeve 不采纳, 生产不变 (NAV 984,331.43 / md5 `350208d1`)。**
买点源级轴至此在**全部形式**上闭合: 重排 / 硬闸 / 软加成 / 独立资金 sleeve。

---

## 1. 问题

10/22 源级轴 11 臂全否后, 唯一未测的收割机制是**独立 sleeve**:
S4 (`chan_divergence_type ∈ {bottom, bottom_fx, bottom_fx_3x, B2}`) 是唯一
信号层截面 α 源 (ex10 ≈ +0.8%, 三 regime 全正), 账簿内 20% 笔数贡献 43% 逐笔收益。
此前的所有臂都试图在**同一本账簿内**偏好 S4, 结果都是重排整本账簿而亏损。
独立 sleeve 给它独立资金, 理论上不扰动主账簿。

## 2. 设计

- 与主账簿**同 130 个选股日**, 同分数排序, 取 top-N, 等权, 现金 0%, 日收盘 MTM。
- 入场: T 日信号 → **T+1 开盘成交**; 出场: 下一调仓执行日。
- 生产口径执行 (与 `bt_execution.py` L2020-2400 逐条对齐):
  - `tradable = raw_vwap>2.0 & volume>100手 & ADV20>5e6 & ~ST` (ST 用冻结时间线逐日判定)
  - 涨跌停: 20% (30/68) / 30% (4/8) / 10%, 0.003 容差, **开盘价/昨收**判据
  - 跳空罚: 买 ×1.03 / 卖 ×0.97, 超过 0.195/0.295/0.095 触发
  - 佣金 0.0001; 印花税 2023-08-28 前 0.001 后 0.0005; 滑点 0.001
  - 买入不可交易则取消; 卖出阻塞则下一执行日重试; 现金不足截断
- 宇宙对照:
  - `s4_any` = S4=1; `s4_only` = S4=1 且 S1+S2+S3=0 (纯 S4 独有)
  - `s4_all4` = 四源齐 (k=4); `ctrl_non4` = S4=0; `ctrl_all` = 全部 buy 行
- 混合: 主账簿 + 权重 w 的 sleeve, 日收益 `(1-w)·r_main + w·r_sleeve`;
  另做 **realcap** 混合 (sleeve 只分 50k/75k 真钱, 其余 450k/425k 跟主账簿),
  排除"日再平衡隐含免费杠杆"的质疑。
- 判据 (预注册): ① NAV 增量 > 150k 噪声地板; ② **ex-top 彩票判据** —
  按 (signal_date, code) 剥离 sleeve 最赚的 top1/3/5 笔, 让下一名补位重跑;
  top3 剥离后优势 ≤ 基线即彩票; ③ 胜率/MDD 改善必须用**负控**对照。

## 3. 生产忠实度: v1 → v2

v1 (`../s4_sleeve_1022/`) 执行层宽松, v2 (`s4_sleeve_1022b.py`) 生产口径。
同一 universe 的差距:

|---|---|---|
| NAV (250k) | 1,895,906 | **1,360,137** |
| CAGR | 43.89% | **35.56%** |

| MDD | −42.78% | **−43.69%** |
| 笔数 | 235 | 233 |

v1 的 1.90M 不能引用。定性结论 (S4 选择效应远强于对照) 在两种口径下都成立。

## 4. 决定性事故: 同代码重跑 NAV 不一致 (已修)

v2 首版同一份代码连跑三次得到 `s4_only_n2` NAV = **1,013,419 / 656,708 / 887,376**,
而逐笔统计 (n/胜率/均值/中位/PF/持有天数) **逐位相同**——
这是**仓位路径**不确定的签名, 不是数据噪声。

根因两处:
1. 买入成交后未立即写 `last_close[c]`。同一执行日的第二笔买入调用 `eq_at()`
   时, 第一笔新仓被估值为 0 ⇒ 预算被压缩 ⇒ NAV 路径依赖买入顺序。
2. 买入顺序来自 `set` 迭代, Python hash randomization 使跨进程顺序不同。

修复: 买入后立即 `last_close[c] = close`; 持仓/买单排序保证确定性。
验证: `PYTHONHASHSEED=0` 与 `12345` 两次独立进程输出
`equity_curve/NAV/交易表` 逐位相同 (`diff` 干净) ⇒ DETERMINISTIC_OK。

**方法论记入铁律: 臂结果的前置条件是"同代码重跑逐位相同";
交易统计相同但 NAV 不同, 必须当成仓位路径 bug, 不能当成噪声。**

### 5.5 负控: 胜率/MDD 改善是分散化, 不是 S4 证据

| 负控混合 | NAV | ΔNAV | win_d | win_5d | win_20d | win_m | MDD |
|---|---|---|---|---|---|---|---|
| ctrl_all w20 | 819,229 | **−165,102** | 47.9% | 51.8% | **61.4%** | **59.4%** | **−17.74%** |
| ctrl_non4 w20 | 840,341 | −143,990 | 48.4% | 51.8% | **62.9%** | **59.4%** | **−17.87%** |

**任何低相关流 (哪怕是负 α) 混进来都会抬高日/5日/20日/月胜率并降 MDD。**
所以 S4 sleeve 的胜率/MDD 改善不构成 α 证据 —— 只认 NAV 与票级 α。

### 5.6 独立性 (设计正确的证据)

与主账簿选股 (date, code) 交集:
- `s4_only_n2`: **0/233 = 0.0%** (122 个有候选的信号日)
- `s4_any_n2`: 26/251 = 10.4%
- `ctrl_all_n2`: 21/252 = 8.3%

s4_only 与主账簿完全不重叠, 所以混合收益不是"同一批票加仓"。

## 6. 判定

**S4 独立 sleeve 拒绝。**

1. 唯一 NAV 正的稳健变体 s4_only w20 增量 +133.6k < 150k 噪声地板,
   配对月度 bootstrap CI 含 0 且跨 0 很宽。
2. ex-top3 后只剩 +27.7k, ex-top5 后 **+0.05% (完全打平)**;
   top5 = 69.5% P&L, 2026 一年 = 55.9% —— 右尾承载, 不可复制。
3. 胜率/MDD 改善被 ctrl_all / ctrl_non4 **负控复现** ⇒ 分散化伪影, 非 S4 α。
4. 增大 N 会稀释: n1 Sharpe 0.919 / n2 0.984 / n3 0.652, 池内排序靠后无 α。
5. 单 sleeve 波动 38%、MDD −43.7%, 独立运行不可用。

S4 的 α 已经在主账簿内通过 `bp_confirm_min=3` **隐式收割**;
独立 sleeve 无法把逐笔 α 转成组合层稳健收益。

**买点源级轴全部形式闭合 (重排 / 硬闸 / 软加成 / 独立 sleeve), 不再重开。**
生产不变: NAV **984,331.43**, equity md5 **350208d13c79a27b2d1d548afeda5012**,
signal md5 **94bca0cc69be9f708e76364976c3957f**。
