## 2. 发现（按严重度）

### F-1【高】读文件失败 ⇒ **静默缩池**（计划 §5 P1 点名的项，仍未修）

`factor_preparer.py:155-159`：任何 CSV 读取/解析异常 ⇒ `return []` ⇒ **该股一行都不产出**，
无计数、无日志、无告警。`:168-169`（历史长度不足）同样静默。
聚合侧 `_compute_factor_data_raw` 只累计**行数**（`total_results`），**不统计股票数** ⇒
少一只股票在行数上不可见。

⇒ 危害不是"少一只"，而是：该股整段缺席 ⇒ 截面排名分母变小 ⇒ **其余全部股票的相对排名被改变**
（中性化、行业均值、ML 的截面 z-score 全部受影响）⇒ 而表面上"回测正常跑完"。

建议（F1 首批）：worker 改为返回 `(code, status, rows)`；聚合端逐只计数
（成功/读失败/历史不足/池外）落盘 + 打印；读失败数 > 0 ⇒ 门禁可见（先报告不拦链）。
成本极低、无收益影响 ⇒ 属"纯工程"。

### F-2【已修，缺测试】批次列集合一致性

`row` 模板先占位条件键（`:214-221`）+ 首批锁定列序、后续 `reindex`（`:528-545`）⇒
结构上保证任意批次切分下列序恒等 ✅。**仍缺计划 §5 P1 要求的"批次划分不变性测试"**
⇒ 建议补一个：同一份输入用不同 BATCH_SIZE 跑，逐列逐值比对。

### F-3【高·用户已知暂缓】行业归属 = 样本中段单一日 ⇒ 行业维度带前视

`factor_preparer.py:664-666`：`mid_date = all_dates[len//2]` ⇒ 行业标签是**样本中段**的行业
分类，被套用到 2011–2026 全历史 ⇒ 中性化、行业因子配置、行业限额全部用它。

- 已知代价（10-22 的 PIT 行业臂）：NAV **645,530 vs 984,331 = −34.4%** ⇒
  **当前回测的收益里含这一块"前视红利"**。
- 用户 10-22 裁定**暂缓** ⇒ 本次不重开，仅登记为因子层最大的已知 PIT 缺口。
- 若推进：必须**单变量**（只换行业归属，其余不动）走同快照两臂，且登记为"已知会掉 1/3 收益"
  的口径修正，不能包装成优化。

### F-4【中】题材热度三处静默降级

1. 计算器加载失败 ⇒ 打印一行后 `concept_calc=None` ⇒ 整列退化到 `ind['concept_heat']` 或 None；
2. 逐股异常 ⇒ 写 **0.5 常数**（`:241`）⇒ 与真实值不可区分；
3. 无计数、无豁免清单。

⇒ 建议：按名册/滞后白名单同样的做法 ⇒ "当日题材不可用"登记 + 计数；0.5 改为 NaN 让中性化
按缺失处理（或加缺失指示列）。

### F-5【中】`ln_cap` 是**估算**市值，缺失时写 0.0

`:224-232`：流通市值 ≈ 成交额/换手率（**代理**，不是真流通市值）；换手率缺失或 ≤0.001 ⇒
`ln_cap = 0.0` ⇒ 与"真实小市值"（tanh 后 ≈0.05）几乎不可区分 ⇒ 市值中性化把这类行当作
真实观测回归 ⇒ 污染中性化。
建议：缺失写 NaN（走中性化的缺失分支），或加 `ln_cap_missing` 指示列。

### F-6【中】标签口径 = 收盘→收盘，与成交口径（次日开盘）不一致

`:267-275`：`future_ret` 用 `close[t+10]` 与 `close[t]` ⇒ 含 T+1 的隔夜跳空，而**实际成交在
次日开盘** ⇒ ML 学的是"不可执行的收益" ⇒ 计划 M1 的"标签与可执行买卖日"未闭合。
已有工具：`core/forward_targets.py::short_net_targets`（次日开盘入场 + 扣费 + 3/5 日净收益），
配置 `ml.target_mode` 现为 `legacy_10d` ⇒ 该臂应按 §1.2 走两臂复核（计划 §0 记载它曾配对验证）。

### F-7【中】行业映射未命中数被统计但**从未输出**

`:663,685`：`unmatched_count` 只累加 ⇒ 行业归类失败的股票数不可见 ⇒ 与 F-1 同族的诊断缺口。

### F-8【低-中】中性化对**小行业**不做去均值 ⇒ 同截面混两种尺度

`factor_neutralizer.py:50-56`：行业内样本 < 3 ⇒ `industry_mean = 0.0` ⇒ 残差 = 原始值
（未去均值）⇒ 与正常行业的残差不同尺度 ⇒ 随后的截面 z-score 会给这些行不同权重。
建议：回退到**全局均值**而非 0（一行改动，方向明确）。

### F-9【残余风险】基本面可用日是"截止日代理"，未表达**逾期披露**

截止日 ≥ 真实公告日 ⇒ 绝大多数情况保守 ✅；但若某公司**逾期**披露（罕见但存在），
截止日早于真实公告 ⇒ 那几天会用到未公开财报。库里**没有"逾期/实际公告日"列** ⇒ 无法识别。
建议：在基本面文件里加一列 `实际公告日`（可空）⇒ 有值时以它为准 ⇒ 才是真正 PIT。

### F-10【正面】缓存键的分层豁免是正确的

- raw 因子缓存键 = `_raw_code_fingerprint`（豁免 `stock_pool.py`/中性化/MTF）+ `_data_fingerprint`
  （**内容**哈希，含概念映射的**实际生效路径**与概念历史/日线）⇒
  池模式/中性化/MTF 变化只换掩码不重算 raw（~3h→秒级），而 10-17 的"概念映射翻钩子静默复用
  假臂"已被这条覆盖 ✅；
- 信号指纹不含 raw 豁免 ⇒ 池模式变化必重生成信号 ✅（方向安全）；
- yaml 按**节**豁免（组合/执行层不参与因子计算）✅；
- 基本面目录内容在键内 ⇒ 改列（如可用日口径）即失效 ✅。
