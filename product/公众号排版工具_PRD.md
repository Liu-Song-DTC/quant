# 公众号排版工具 产品文档

版本: v0.2 (2026-08-17)
状态: 立项

---

## 1. 产品定位

**一句话**：通用公众号排版工具，内置行业场景模板体系——通用排版能力打底，行业场景做深度。

产品结构分两层：

```
┌─────────────────────────────────┐
│  行业场景层: 财经 / 科技 / 教育 / …  │  ← 差异化所在
├─────────────────────────────────┤
│  通用排版层: 编辑器 + 主题 + 复制    │  ← 与 mdnice 对齐
└─────────────────────────────────┘
```

**切入策略**：以财经场景首发（创始人自有真实场景，吃自己的狗粮），验证"行业场景"这个差异化成立后，扩展其他行业。

## 2. 背景与痛点

### 2.1 为什么现在做

- 创始人本人在做量化公众号，每天复盘文章的排版+图表耗时 1 小时以上
- 现有工具（mdnice、135、秀米）都是**通用排版**，行业专属需求无人覆盖：
  - 财经博主要涨红跌绿语义、盈亏表、K线图
  - 科技博主要代码块样式、终端截图风
  - 教育博主要公式渲染、知识点卡片
  - 法律/医疗等垂直领域各有各的格式规范

### 2.2 目标用户痛点

| 痛点 | 现状 |
|------|------|
| 通用工具排版后还要手动做行业专属组件 | 表格高亮、图表全靠 Excel 截图 |
| 行业模板缺失 | 每天从零搭结构 |
| 数据型内容（表格/图表）排版成本高 | 改一个数字全篇格式乱 |

### 2.3 市场规模

- 公众号生态：2,000 万+ 公众号，活跃创作者数百万
- 全部创作者都是潜在用户（通用层）
- 行业场景层逐个行业渗透，财经只是第一个

## 3. 竞品分析

| 竞品 | 定位 | 行业场景 | 价格 |
|------|------|---------|------|
| mdnice 墨滴 | 通用 Markdown 排版 | 无 | 免费+会员 |
| 135 编辑器 | 通用富文本排版 | 弱（通用模板） | 免费+会员 |
| 秀米 | 通用排版 | 弱（通用模板） | 免费+会员 |
| 壹伴 | 效率插件 | 无 | 会员 |
| **我们** | **通用排版 + 行业场景体系** | **深度场景（财经首发）** | 免费+会员 |

差异化结论：**通用能力对齐竞品（做到 80 分即可），行业场景是竞品没有的增量（做深做透）。** 用户在 mdnice 排版时缺的从来不是编辑器，是"这个行业的文章长什么样"。

## 4. 产品功能

### 4.1 通用排版层（所有用户免费可用）

1. Markdown 编辑器 + 实时预览（桌面 Web）
2. 主题样式 5+ 套，持续新增
3. 一键复制到公众号（样式内联、图片上传）
4. 基础组件：引用、代码块、图片组、分割线

### 4.2 财经场景（V1 首发，免费）

1. 财经主题 3 套（深色专业 / 浅色商务 / 极简）
2. 盈亏表格组件：自动识别盈亏列 → 涨红跌绿、加粗
3. 复盘文章模板（日复盘 / 周复盘 / 月复盘）
4. 图表组件：批次表现条形图、收益曲线、漏斗图
5. 持仓数据粘贴 → 自动生成表格（MVP 简版）

### 4.3 其他行业场景（V2+，按需扩展）

| 场景 | 组件示例 | 优先级 |
|------|---------|--------|
| 科技/编程 | 代码块主题、终端风截图框 | 高 |
| 教育 | 公式渲染、知识点卡片 | 中 |
| 职场/HR | 简历式卡片、流程图 | 中 |
| 医疗/法律 | 专业术语脚注、引用规范 | 低 |

### 4.4 付费功能（V2）

1. 场景组件高级版（数据导入自动化、图表定制）
2. 场景模板市场（用户投稿模板，创作者分成）
3. 文章历史管理、多账号管理
4. 定价：¥19/月，¥99/年

## 5. 技术方案

| 模块 | 选型 | 理由 |
|------|------|------|
| 前端 | Web 应用（桌面优先） | 绕开个人小程序无法接支付的问题 |
| 编辑器 | CodeMirror 6 + markdown-it | 轻量可控 |
| 图表 | ECharts | 已有使用经验 |
| 后端 | Python FastAPI | 复用创始人能力栈 |
| 支付 | 微信支付（V2 前注册个体工商户） | |
| 部署 | 单台云服务器 2C4G | 月成本 ~¥100 |

## 6. 商业模式

```
免费层: 通用排版全部功能 + 财经场景基础版
    ↓ 转化点: 高级场景组件 + 模板市场 + 自动化
付费层: ¥19/月 / ¥99/年
```

## 7. 获客策略

1. 自有量化公众号首发（"我的复盘用这套工具做的"）
2. 场景化内容营销：每扩展一个行业场景，产出该行业的教程文
3. 模板免费换流量
4. 中小博主 KOC 合作

## 8. 合规边界

1. 工具中性——不为用户生成内容负责
2. 用户协议明确禁止违法内容
3. 不提供行情数据源（用户自带数据）
4. **红线：永远不做"自动荐股"功能**

## 9. 风险与对策

| 风险 | 等级 | 对策 |
|------|------|------|
| mdnice 免费功能已够用，用户不迁移 | 高 | 行业场景是强差异化；财经首发场景有真实用户（自己）验证 |
| 付费意愿不足 | 高 | V1 全免费验证使用数据，V2 用"省时"锚点定价 |
| 个人无法开通微信支付 | 中 | 注册个体工商户 |
| 场景扩展投入大 | 中 | 场景插件化架构，每个场景独立评估 ROI |
