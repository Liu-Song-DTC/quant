# ML 架构与目标复核（2026-10-27）

## 模型文件必须同时拥有预处理口径

旧元数据保存树、特征名和交叉配对，但预测时仍受调用者当前白名单、交叉开关、市场状态交互开关、缺失指示位开关和填充阈值影响。输入列顺序还会改变“前10项”的状态交互来源。这意味着同一组树未必代表同一个预测函数。

本次补齐已拟合预处理快照：训练成功时冻结白名单、交叉/状态/缺失指示位设置及阈值；模型保存并载入时恢复。状态交互的来源列在训练时确定，预测不再按输入列顺序重挑。未知预处理版本在替换现有模型之前拒绝。旧模型没有完整预处理证据时，仍保留兼容路径，不宣称已还原不可得的训练参数。

测试明确改变载入时白名单、各开关、缺失阈值以及预测输入列序，保存/载入后的预测仍逐值一致；拟合后修改外部配置的白名单也不能改变已拟合模型。连同市场级特征、模型往返、验证标签隔离及缺失指示位，共8项测试通过。

训练过程先在候选对象中构建新状态，成功后才替换原状态；样本不足或拟合异常时保留原有模型、交叉配对及预处理证据。测试在拟合阶段注入异常，并确认原模型仍可给出相同预测。这不等于对共享对象并发训练/预测作线程安全承诺。

## 横截面特征与市场时间序列分层

旧流程对所有数值列按日期做截面标准化。同日共享市场特征会被归零，不能靠在白名单加上美债、汇率、波动率名字解决。

新增显式`ml.market_feature_cols`，默认空，现有生产配置不变。被声明的市场特征保留时间序列值；同日跨股票存在冲突值时拒绝；不对其构造无意义的同日百分位交叉。模型保存其训练时的市场特征声明，载入时恢复，不服从调用者任意改变。数据发布时间仍由上游as-of契约负责，保留数值不代表允许前视。

默认配置下，在确定性训练样本上与变更前实现比较，特征列及预测逐值相同。这里的兼容验证不是完整收益回测，也没有声称新宏观信息已接入或产生收益。

## 四种目标的机制探针

`.review_runs/ml_objective_probe_20261027_v2/`：从固定评分臂的原始因子缓存中按代码SHA256固定抽取256只股票，比较2022、2024、2026年三个前推窗口。每个目标共享相同输入特征、树容量、种子和拟合/早停/测试时间区间；用标签结束日分别隔离拟合与早停、早停与测试边界。目标为次日开盘入场后3/5日平均扣成本盯市收益。

这是小样本机制探针：不含生产日历股票池掩码、行业中性化、组合仓位或成交风控，不是完整回测；已有研究历史不是未使用过的样本外。分类概率未经校准，不能直接解释为实盘准确胜率。首轮因pandas只读数组的原位操作失败，v2用非原位布尔运算修复，失败目录不覆盖。

## 评分装配与筛选人群变化

单位臂与统一评分臂的选股决策键共有92项、移除67项、新增70项。流式读取两份信号，在229个决策键上配对；被移除组最终分数下降中位数约0.140，原始因子值及纯因子分变化中位数为0，ML分变化中位数约0.000324。重建的基本面直接加分变化在移除组比新增组更负，但该项发生在ML融合之前，不等于最终分数变化的完整因果归因。

被移除67项的3/5日净标记胜率为56.72%/50.75%；新增70项为44.29%/38.57%。这解释了整体短期胜率下降对应的人群变化。人群由此前持仓和筛选链共同决定，不能把它当成随机对照，更不能仅针对这67项回填例外。

后续先完成增长压缩全量臂；串行队列随后在原始冻结基线上只修复ML掩码覆盖问题，完整重训、生成信号和回测。评分门槛、基本面直接加分、ML目标与风险辅助分别做独立验证；暂不改变调仓节奏。
