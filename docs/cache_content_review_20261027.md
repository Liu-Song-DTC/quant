# 输入内容与缓存复核（2026-10-27）

因子缓存的数据指纹原来依赖绝对路径、文件大小和mtime。信号重用主要比较mtime。其后果是同长度改写再恢复mtime可能误命中；相同内容移动目录或仅触摸文件也可能触发昂贵重算。研究快照原先已有内容检查，但不能据此认为生产因子/信号缓存也已具备内容检查。

修复引入共享的SHA256输入身份：价格按证券代码绑定，财报按CSV文件名绑定，额外输入按固定角色绑定。目录位置和mtime不参与内容身份；读取失败不得伪装成缺失。选定的可选输入缺失有独立标记，空文件和缺失不同。读取期间检查文件身份与时间状态；此检测不能取代封存数据或更新锁对并发写入的隔离。

因子构建和日历股票池使用这份内容身份。信号复用检查输入身份及信号CSV本身的内容，防止同长度改写信号后继续复用。生成前后比较源码与数据身份，变化时拒绝发布成功的缓存记录；输入记录与代码记录原子写入。没有新内容记录的旧信号将要求重生成一次。

信号输入范围包含QFQ行情、财报、证券元数据、概念映射/版本/历史/日序列/成立日、市值白名单和信号实际使用的4份另类数据；个股两融增强开启时还包含margin_detail。宏观数据和组合层独立使用的其他事件不是这里的信号输入，执行层仍须记录自身完整输入。此改动不等于所有缓存或依赖链审查完毕。

当前验证9项：同长度改写并还原mtime、相同内容跨树、仅触摸文件、证券代码绑定、缺失与空文件、权限错误、读取中原子替换、信号CSV与输入绑定、真实复用门禁，以及条件启用的两融输入；另含未来标签不改变当前特征的回归。部分测试方法覆盖多个场景。

这是缓存身份与失效规则修复，没有修改因子数值公式、ML目标或调仓规则。已经封存的收益实验不修改。后续独立检查完整回测重放与性能开销；读取大型数据及信号CSV的内容会增加启动I/O，不能为了省掉这一步而恢复mtime当作内容的假设。

另发现ML查询掩码覆盖原信号有效性掩码，已在工作区分开变量并通过专门测试；其数值行为影响待独立回测，不混入本次缓存修复提交。
