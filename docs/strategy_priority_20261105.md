# 策略端优先路线（基于已完成审查）

## 已确认的结构问题

- 封存候选池 3,458 个可标记样本、87 个可算 IC 的选股日：ML 分数的 5 日平均日截面 IC 为 0.118；最终信号分约 -0.036，组合评分约 -0.030。信息从 ML 到最终排序时没有有效保留。
- 在 94 个真实 top-K 边界上，单独按 ML 分数改选 53 次，5 日胜率较原入选者低 4.26 个百分点。全池 IC 不能直接证明边界换股有效。
- 已入选 161 只股票的 ML 分位呈非单调：中间 40%–80% 桶 5 日胜率约 55%，最高 20% 桶仅 38.5%。现有高 ML 软罚已在组合中启用，说明简单提高 ML 权重或直接买最高 ML 都不合适。
- 当前 ML `target_mode=legacy_10d`，短期 3/5 日胜率是用户优先目标。目标、验证 IC 和组合边界需用同一时距及净成本口径核对。

## 连续实验顺序

1. 先复核从原始因子、ML 预测、融合分、组合有效分到最终入选的同日分数和排序变动，输出每层丢失的 3/5 日赢家数量及原因。
2. 以 2021–2023 为训练期，2024–2026 为固定检验期，比较现有融合、训练期确定的短期目标融合、以及 ML 只作风险门控三种方案；采用真实 top-K 边界和净成本标签。
3. 通过上述离线门槛的方案，才用同一封存数据与信号生成流程做完整账户回测；比较 NAV、逐年收益、1/3/5/10 日胜率、最大回撤与换手。未通过则回到因子质量和 ML 特征契约，不调成交参数追收益。

现有 AH 持仓加仓实验只作为风险旁证，不改变这条主线的优先级。历史检验期已经被反复研究，不能称为全新样本外。
