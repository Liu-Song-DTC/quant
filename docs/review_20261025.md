# 2026-10-25 审查、修复与回测记录

目标：可靠性、回测与实盘一致、尤其 3/5 日的扣费选股胜率、回撤、收益与性能。
用户已授权自主修复和优化；这不等于授权制造或推定券商成交。

## 已实现的可靠性修复

- 当日开盘成交不再读取当日收盘后的选股资格；买入资格取上一决策日，卖出独立于买入池。
- 停牌开盘不前向填充；全部实际持仓始终参与权益和风控计算。
- 空目标与无决策分开，选股异常中止回测。
- 不再按未来收益删掉预测日样本。均值填充仍保留；当前实现会把池外掩码的因子 NaN 填回截面均值，因此池外样本可能重新进入因子排名和 ML 训练。均值填充本身不是错误，但这与“池掩码自动继承”的注释不一致，需用独立成员资格标记隔离。
- 周/月线使用固定日历结束日；支撑压力位只使用已确认枢轴。
- ML 先划分并隔离标签窗口再选特征；近期权重方向纠正；按逐日 Rank IC 验证。
- ML启用时依赖/训练异常中止信号生成，不得静默降级或沿用部分预测；模型成员原子写入，元数据最后发布并记录校验和，任何成员缺失/损坏拒绝加载。
- 标签终止日期显式保存；训练窗口按实际终止日期再次校验。
- 行业/市值中性化开关接入；市值代理改为真实成交额与换手率计算。
- 熊市计数、调仓日期和板块状态跨日保存；调仓单位显式配置，默认保留原自然日口径。
- 计划订单与实际持仓、现金分开；实际回报按 fill ID 幂等入账并保留部分成交。
- 已有实际持仓却缺少账户账本时拒绝按成本猜测现金；独立回报导入支持隔离目录并验证重发幂等。
- 计划、账户、持仓和策略状态通过持久化日志一起提交，订单最后发布；同日重复运行只重放原订单。
- 熊市免算只推进实际账户，不再人工向历史回测净值追加平盘行。
- 旧实盘入口统一；修复推送和风险画像读取错误账户/订单目录的问题。
- 主链传播管道错误并拒绝并发；配置仅修改 todate 时不再被洁净闸误拦。
- 信号缓存绑定执行上下文，恢复同一市场状态和行业分母，防止首次运行与缓存重放不一致。
- 已平仓胜率改为净现金流，计入加减仓及交易费用；年度收益包含年初第一个交易日。

## 券商回报接口

输入 CSV：

```csv
run_id,seq,stock_code,order_type,price,volume,fill_id,order_status,ts,fees
20261022,1,600000.SH,BUY,10.00,400,F001,PARTIAL,2026-10-23 09:25:00,2.00
20261022,1,600000.SH,BUY,10.01,600,F002,FILLED_ALL,2026-10-23 09:25:01,3.00
```

- `run_id` 是决策日 YYYYMMDD，`seq`、`order_side`、`order_quantity`、`order_id` 随订单发布。
- `volume` 是本条的增量成交量，不能填累计成交量。每笔实际成交有独立 `fill_id`。
- `PARTIAL` 不终结订单；`FILLED_ALL` 的累计成交量必须等于申报量。
- `REJECTED`、`SKIPPED_NOT_ARMED` 必须为零成交量；`UNFILLED_CANCEL` 终结未完成余量。
- `fees` 为本条真实总费用；缺失时按配置估算并在 `execution_history` 标记 `fees_estimated`。
- 重复回报不重复入账；同一 fill ID 内容变化、超量成交、未知订单或错误方向会拒绝整批入账。
- 没有回报不表示已成交，也不表示已撤单。禁止覆盖未完成订单。
- 同目录的 `.live_state_journal.json` 是崩溃恢复日志，不应手工删除。

旧账本如有估算 pending，必须先按真实券商账户核对现金和持仓才能迁移；程序不会擅自把估算当真实成交。
实际券商执行器和真实权限、成交时段仍按 `strategy/qmt_bridge/PROTOCOL.md` 校验；本轮不发送真实委托。

## 回测计划与判据

1. 保留修改前生产产物为历史参考，不把不同数据状态的旧数字当严格配对证据。
2. 全市场、2021-01-04 至 2026-10-23 重建因子、模型、信号和账户回测。
3. 在同一信号、同一市场与行业上下文上重放基线；要求净值一致后才开展执行层实验。
4. 预定义最终账户风险限额臂：单票35%、行业50%、总敞口98%、持仓12只；削减部分留现金。
5. 同时报告净收益、回撤、Sharpe、净交易胜率、1/3/5/10日净盯市胜率及样本量。
6. 优化默认关闭，只有配对结果支持才采纳。不得用删除无法退出样本、减少到极少数交易来虚增胜率。

短期目标臂（在看到该臂结果前定义）：`ml.target_mode=net_short_3_5`，
使用次日开盘入场后3/5日的平均净盯市收益作为训练标签；预测截面不按未来收益删行。
采用4个信号生成 worker 以控制内存；这不是增加策略的拟合自由度。
判据：3/5日平均净胜率和平均净收益改善，累计收益与回撤不出现明显恶化，
分年和剔除最大盈利交易后仍有合理表现。达不到则保留原目标，不能只展示有利指标。

历史区间已经反复研究，不能把它重新标记为未使用过的样本外。历史 PIT 缺口和实际成交近似见 `disclosure.md`。

## 结果

第一轮修正版完整重建已完成，**不符合优化目标，不作为成功版本发布**。
该臂同时启用了原来未实际生效的市值中性化，并将旧策略的10自然日调仓改为10交易日，
因此除了必要的因果性与记账修复，还包含需要单独归因的策略变化。

| 指标 | 旧产物参考（非严格配对） | 第一轮修正版 |
|---|---:|---:|
| 累计收益 | 440.62% | 2.37% |
| 最大回撤 | 19.78% | 28.60% |
| Sharpe | 1.5621 | 0.1159 |
| 3日净盯市胜率 | 53.01% / 166笔 | 43.70% / 119笔 |
| 5日净盯市胜率 | 47.59% / 166笔 | 43.70% / 119笔 |

旧产物来自保留的历史结果，不能用以上差值声称任何单项修复造成收益变化。
第一轮修正版闭环净交易胜率47.90%，旧产物的价格胜率口径不同，不直接比较。
分年收益为2021 -25.66%、2022 +17.90%、2023 -12.74%、2024 +26.98%、
2025 +32.81%、2026 -20.62%。结果位于 `.review_runs/corrected_20261024/corrected/`。

同一信号的执行上下文重建及最新批量信号读取已通过完整1405日重放，
`equity_curve.csv` 与第一次执行逐字节一致（最终权益255,934.8961275792）。
该一致性验证只支持性能修改未改变本臂交易结果，不代表策略有效。
下一步对自然日调仓、旧单指数市场上下文分别进行单变量归因；
因果性修复不得为了恢复收益而撤回。

自然日调仓单变量臂已完成：相同信号、市场/行业上下文及其余逻辑，
累计收益202.50%，最大回撤17.23%，Sharpe1.0813，最终权益756,255.0346984578。
此结果支持保留原来10自然日调仓；不支持将10交易日当成必须修复。

测试中的 `1200` 样本、`12` 特征及负IC来自固定随机数的合成数据，
用于验证训练拆分与标签隔离，日志已增加 `REGRESSION_RANDOM_DATA` 标记。
正式滚动训练使用真实截面数据，不能将合成测试的IC解释为实盘模型效果。

## 均值填充与股票池口径探针（2026-10-25）

按用户要求仅运行离线脚本，不运行新的组合回测。脚本
`strategy/analysis/probe_pool_imputation.py` 对已存 raw-factor parquet 及相同月度
membership 快照抽取60个因子日，比较“中性化将 NaN 填均值”与“恢复池外 mask”的
截面规模、因子名次和 IC；只用5个代表因子，不训练模型、不调参。

全样本60日平均每个截面池内4,376只，池外但原始因子有值约83只，约为池内的1.9%；
填充后这约83行重新进入完整样本。2021年起51日平均池外完整行约80只。池内单因子
次序相关为1.0，但平均百分位变化约0.48个百分点；五因子等权代理分数的秩相关
0.99987，Top10%换入换出约1.06%。池外行进入后，抽样单日因子 IC 的绝对变化均值
约0.00267，因子-日期符号翻转率约1.2%。这是明确的池成员口径泄露，不过这些局部
指标尚不能把它归因为主要收益损失，也不能替代全因子、真实动态权重、逐笔持仓对照。

因此，均值填充作为一般缺失值处理并非天然错误；但当前月度股票池掩码会被中性化
填充重新覆盖。均值填充值也会使 ML 的“至少一个特征非空”过滤失去成员资格识别作用，
所以池外行可能进入排名和监督训练。此前 60 日探针只量化了因子排名/IC 的局部变化，
不能量化这批 ML 训练样本对净值的影响，也不能证明它是收益回退的主因。若策略有意
使用更大历史母池，应明确把该母池定义为训练与选股范围；否则应在填充后用独立的
PIT 成员资格掩码过滤训练和选股样本。完整样本探针产物在
`.review_runs/pool_imputation_probe_20261025_n60/`。

已有的同信号调仓单位配对结果也需纳入原因分析：10交易日臂累计收益2.37%，
10自然日臂202.50%，最大回撤从28.60%降至17.23%。这是大幅收益差异的直接单变量
证据；池外填充的单独贡献尚未通过同一信号屏蔽/填充成对实验确认。

短期标签臂 `.review_runs/net_short_calendar_20261025/` 在首个 ML 窗口后中止，
没有生成可比较的完整信号或回测结果；该目录产物不用于任何策略结论。

### ML 训练窗脚本审计与修正

使用相同 raw-factor cache 扫描24个真实滚动训练窗口（只读日期、标签结束日和收益标签，
没有调用 XGBoost）。修正前，内部训练标签约2.97%跨越内部验证起点；特征筛选发生在
内部分割之前，约21.1%的验证日期标签参与特征选择；近期90天仅占训练权重约11.1%，
与代码“近期更重要”的注释相反。修正后，训练划分先按 `label_end_date` purge，
交叉特征仍用完整当日截面计算，但选因子仅看已成熟的训练标签；采样权重改为随样本
年龄递减；验证 IC 按每日 Spearman RankIC 汇总。

相同算术探针复核24个窗口，purge后训练标签重叠为0，验证标签进入训练期特征筛选数为0。
修复只做了训练逻辑修改和静态/日期探针，未重训模型、未生成信号、未跑组合回测，
因此目前不能声称3/5日胜率或净值已经改善。`strategy/analysis/probe_ml_walkforward.py`
及其逐窗口输出在 `.review_runs/ml_walkforward_probe_20261025/`。
