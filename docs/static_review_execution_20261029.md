# 成交层静态审查 (2026-10-29, 交接计划 §3 任务3 / §6)

方式：**只读代码静态追踪**（未跑回测）。
清单：`docs/source_inventory_execution_20261029.csv`（6 行）。

一句话结论：**生产撮合路径（向量化）比预期扎实——T+1 开盘成交、涨跌停按开盘判（因果）、
按板块分档的阈值、真实成交额/真实收盘做闸、印花税按日期分档、现金不足按比例缩量并取整手、
成交明细独立落盘并可重放（误差 3.6e-08）；缺口集中在三处口径不一致（科创板整手、冲击成本被关闭、
涨跌停"识别"与"闸"两套口径）+ 旧 BT 路径是死代码。**

## 2. 发现（按严重度）

### E-1【中】回测侧缺**科创板整手规则** ⇒ 回测可买集合 ⊋ 实盘

- 实盘：`generate_trade_orders.py:728-733` → 688/689 **最小 200 股 + 1 股递增**，其余 100 整手 ✅；
- 回测（向量化，`bt_execution.py:2402`/`2456`）⇒ **统一 100 整手** ⇒ 回测可以买 688 的 100 股
  （实盘会因不足最小申报而跳过）⇒ **回测能买、实盘买不到** ⇒ 违反"实盘=回测同一套标准"。
- 量级：只有当目标金额/股价 < 200 股时触发 ⇒ 6.25 万仓位需股价 < 312 元 ⇒ 大多数 688 不触发
  ⇒ 影响小，但**口径不一致**需登记。
- 建议：抽一个共享的 `_lot_shares()` 给两侧用（回测侧按 code 前缀套用）⇒ 属工程修正，
  但会改回测结果 ⇒ 按 §1.2 走臂（预期影响极小）。

### E-2【中】冲击成本模型存在但**生产关闭** ⇒ 无成交量/冲击/部分成交建模

- `cost_model.impact_cost_enabled: false` ⇒ `execution_fills.csv` 的 `impact_cost` 恒 0
  （metrics 里 impact_cost = 0.0 ✓ 自洽）。
- 已实现的模型是合理的（participation = |size|/ADV，ADV shift(1) 无前视；base×p^0.5，下限 5bp），
  **但 participation > 1 时仍给很小的冲击**（0.03%×1^0.5 ≈ 3bp）⇒ 模型**无上限保护**，
  若打开开关需先封顶。
- 后果：回测可以买入超过当日成交量的规模（只受现金约束），成交价只有滑点 + 跳空折让
  ⇒ 计划 E1 明确列出的"成交量/冲击、部分成交"**未建模**。
- 对当前 25 万账户、单笔 6.25 万、池内 ADV>500 万 ⇒ 参与率通常 <1.3% ⇒ 影响有限，
  但在极端缩量股上失真。

### E-3【中】涨跌停的"识别"与"闸"是两套口径，且**未按规则生效日**分段

- **闸**（生产路径，因果 ✅）：按开盘相对昨收 + 板块阈值 + 0.3% 容差；
- **识别**（`_LIMIT_DATA`，`bt_execution.py:908-942`）：按**收盘**涨幅 `cp≥9.5` / ST `|cp|∈[4.5,5.5]`
  + 振幅启发式 ⇒ **不分板块** ⇒ 20% 板的 +10~19% 涨幅会被标成"涨停"；且 ST 的 5% 阈值
  **未按 2026-07-06 新规**（主板风险警示 5%→10%）分段 ⇒ 计划 §5 P1 的"交易规则按市场/板块/
  IPO 天数/历史日期实现"未满足。
- 生产影响有限（`_LIMIT_DATA` 主要喂旧 BT 路径与统计），但**规则表缺失**是计划明确要求补的。

### E-4【低-中】佣金按比例（万5），**未建模最低 5 元**

- 现规模无影响（6.25 万仓位 ⇒ 佣金 31 元 ≫ 5 元）；若账户缩小或拆单变多 ⇒ 成本被低估。
- 建议：成本模型加"佣金下限 5 元"项（真实券商规则），按 §1.2 评估。

### E-5【正面】成本与规则的时点处理是对的（值得记录，避免以后误改）

- 印花税**按日期分档**（费率变动被建模）且只在卖出侧 ✅；
- T+1 每日重置 ✅；
- ADV/均额均 `shift(1)` ⇒ 无前视 ✅；
- 涨跌停容差 0.3%、跳空折让与"不可能成交价"的处理（10-24 关掉 3% 折让 + 涨跌停闸兜底）✅；
- 现金约束是"按比例缩量 + 逐笔复核 + 取整手"，不是"先到先得" ⇒ 不会因顺序不同而漂移 ✅；
- 成交明细四项成本齐备且可独立重放 ⇒ 目标/实际分列的证据链完整 ✅。

### E-6【低】旧 BT 路径与向量化路径**双实现**，旧路径是死代码风险

`BacktraderExecution`（:1811-2035）自承"向量化路径已替代 BT 路径，此方法暂未使用"，
但它仍在文件里，且与生产路径**有实质差异**（统一 100 整手、冲击未启用、`_estimate_impact`
依赖未填充的 `_adv_cache`）⇒ 谁若复活它 ⇒ 口径静默漂移。
建议：标注为 deprecated 或删除（需用户裁定）。

### E-7【已核对，非问题】退市股在实盘不可交易

118 只退市股 `raw_data` 里只有 `qfq.csv` 没有 `none.csv` ⇒ 实盘拿不到裸价 ⇒ 不出单；
回测侧它们在日历池之外（名册外 137 个 qfq 文件不在池内）⇒ 两侧一致 ✅。
