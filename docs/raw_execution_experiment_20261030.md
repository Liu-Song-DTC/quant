# 裸价成交回放：数据契约与实验门槛

现行向量化回测在 `strategy/bt_execution.py::_vectorized_backtest` 中把
自算 QFQ 开/收盘价用于股数取整、现金、持仓市值和收益。对应的实盘
下单读取裸价。2026-10-28 截止封存样本有 387 笔买入；按相同名义
金额换算成裸价整百股，301 笔股数不同，66 笔加仓金额低于一手裸价。
这只是成交模型的可行性诊断，不能把名义金额差直接加减到原回测净值。

实验须保持同一份已封存信号/选股决定，另外构造独立的裸价执行与估值
分支。开盘按裸价确定交易股数，保留现金不足、涨跌停、T+1、停牌、
最小交易单位和既有滑点/费用约束，收盘按裸价估值；股权登记日收盘
的真实持仓决定权益归属，除权日处理股份变化，现金红利在**明确的
到账日**成为可再投资现金，提前只记应收。组合权重或信号若依赖现有
QFQ 成交反馈，需在两臂中按各自真实模拟净值重新计算，不能在
不同现金/股数状态下复用另一臂的成交记录。

本地 `events_table.pkl` 只有 `ex_date, s, D, mult, src`，没有现金
发放日、新股可流通日及税费记账；`corporate_actions.pkl` 同样只有
`code, ex_date, s, D`。仓位跨越的 21 次事件中，3 次涉及送转；
当前 21 条事件表 `s,D` 均非缺失。现有的登记日侧车经
`audit_action_record_coverage.py` 核验 **21/21** 有来源记录，但此前
它们存于隐藏目录，未进入封存数据指纹；已修复以后封存会复制并哈希
这些侧车，旧 run 不可追溯地套用后刷新的侧车来声称 PIT。

既有 `docs/action_terms_issuer_verified_20261029.csv` 通过
`audit_issuer_settlement_terms.py` 核验发行人公告 **4/21**（其中
2 次送转）；另 **17 次**只具备供应商条款，仍须逐一查实施公告并
封存登记、除权、红利发放、新股可交易日期和差异化分配条款。
对应的审计说明在 `docs/action_record_date_sidecar_20261029.md`。
缺任何关键字段的持仓事件都不得静默假设当天到账。

当前本地事件表不含红利到账日，不能把 `ex_date` 字段假定为可用现金日；
实施公告中的具体日期和差异化条款须独立核验并随实验封存。

先以现金分红、送转、无公司行为三只股票构造可手工对账的回放样例，
检验除权日前后 `现金 + 应收 + 裸股数 × 裸价` 与 QFQ 价格财富变化
的关系；再上全池同信号的成本净值成对实验，输出逐日权益、买卖差异、
真实整手不可成交次数、1/3/5 日胜率、2026 年回撤和完整年度指标。
税费及同日到账无法证实前不得用该分支声称“实盘收益已经证明提高”。

### 主循环隔离接线（研究开关，仍禁止完整收益外推）

`QUANT_RAW_EXECUTION=1` 只在向量化执行层切换到原价开盘、最低、
收盘价；信号输入继续为 QFQ，涨跌停／跳空的跨除权判据仍用 QFQ
收益比，避免把除权造成的裸价落差误判为跌停。原价收盘缺失时只
用已有最后真实收盘**估值**，绝不用此前开盘伪造成交。当前尚未把
发行人现金／股数账本接入主循环：任何持仓跨越融合事件表的除权日
都会直接抛错并停止研究臂，禁止产出伪造的“全期原价收益”。

`test_review_regressions.ExecutionTests` 的无事件微型执行验证
按原价 100 股取整、除权日买入不因未经调整的假跌停被拦截，
而跨未核实的持仓事件会中止；原默认执行回归也仍通过。
这是**研究臂接线阶段**，不是生产默认变化，更没有全量配对 NAV。
后续需用发行人公告补齐 17 个持仓事件与原价账本，实现真实股数／
应收／可用现金一致后，才能解除持仓事件门禁并做完整回测。

### QFQ 落盘到分位造成非除权段收益偏差（只读审计）

`data/rebuild_table_qfq.py` 对 OHLC 执行 `.round(2)` 再落盘。无公司行动时，
乘性 QFQ 和裸价的**收盘到收盘区间收益**原本应相等，但各日单独舍入使
两日收益比不再严格相等。通过
`strategy/analysis/audit_qfq_rounding_on_trades.py --run
.review_runs/alt_preobs_proxy_20261031 --out
.review_runs/alt_preobs_proxy_20261031/qfq_rounding_event_free.json`
检查封存的已平仓记录：141 笔在持仓期间无除权事件，66 笔的收盘收益
偏差超过 1bp，最大 14.49bp，绝对偏差第 95 百分位 5.34bp。
报告附逐交易 CSV；这是区间**收盘收益**的差异，不等于成交 P&L、
更不能推断全组合净值差值。当前只审计，不改动生产复权文件：提高精度
会改写大量历史文件及缓存指纹，需要隔离实验臂和全量回测再判定收益、
短期胜率及回撤的影响。

根因交叉核对：用相同封存原价、融合事件表和 `qfq_anchor.json` 调用
`build_one` 重算 002526 全部 2,452 个重合交易日；未舍入收盘价按
两位小数舍入后与封存 QFQ 收盘逐日一致。例如 2023-01-16
未舍入 2.271941 → 写盘 2.27，2023-02-03 未舍入 2.458811 → 2.46。
这确认该股票的偏差来自写盘精度，而非这两日之间存在遗漏除权事件；
其他股票仍需在独立精度实验臂复核，不能外推成已实现收益提升。

同样的方法扩大到封存的 151 只实际成交股票：逐股用各自冻结锚、封存
事件和封存裸价重算历史收盘，已重合的 QFQ 文件行按两位小数还原后
**151/151 股票均无不匹配日**；单日未舍入价与文件价格最大相差
0.005 元。该核对针对已交易股票的已存历史行，表明精度问题可以在
不改事件计算的前提下单独隔离；并不代表全市场股票或新增持仓已验证。

### 高精度 QFQ 对已入选股票短期动量的只读敏感性探针

`strategy/analysis/probe_qfq_precision_signal_proxy.py` 以封存的原价、融合
事件表、每股冻结锚重算未舍入 QFQ，先严格验证重算价四舍五入至分后
与封存 QFQ 收盘一致，再比较旧回测实际入选日的 3/5/10/20 日动量。
结果保存于同一封存 run 的 `qfq_precision_selected_momentum.json/.csv`：
161 条入选记录、151 只股票，每种周期均为 161 个可比值；3 日动量
最大绝对差 12.94bp（1 次正负翻转），5 日 45.45bp（0 次），10 日

对照全量回测前不据此推断收益会改善，也不改生产价格文件。

### 141 笔无公司行动交易：固定封存轨迹的原价对账（2026-10-31）

`.arms/replay_raw_event_free_fills_1031.py` 在
`alt_preobs_proxy_20261031` 上按同一事件过滤规则选出 141 笔已平仓交易，
覆盖 133 只股票、1,772 笔实际模拟成交。它固定原交易日期、方向和股数，

复原；封存 QFQ 的投入、回收和已实现收益全部重构成功，最大现金误差
低于 `1e-10`。输出为同目录 `raw_event_free_fixed_fills_20261031.json`
及 `_trades.csv`、`_fills.csv`。

141 笔中，原价与 QFQ 的逐交易已实现收益率绝对差有 63 笔超过 1bp，
第 95 百分位为 5.266bp，最大 15.848bp；平均差（原价减 QFQ）为
−0.093bp，中位数约为零。两臂均为 74/141 笔盈利（52.4823%），没有
盈亏符号翻转。把原价收益率乘以各自封存 QFQ 投入本金后，本金归一化
P&L 差合计为 −179.40 元；这仍只是逐交易算术汇总，不是组合 NAV。

固定股数时，原价与 QFQ 价格水平对应不同名义本金，因此未归一化的
P&L 差不能解释为财富增加。该对账也没有重新确定裸价整手、现金缩放、
成交可行性、公司行动或未平仓头寸，禁止据此推断全期收益改善。

### 主循环账本接通与精确财富桥接（2026-11-01）

`QUANT_RAW_EXECUTION=1` 研究臂已把 `RawCorporateActionLedger` 接入主循环：
原价买卖只通过账本扣款／入账，分别保存可交易现金、应收红利、可交易股和
受限送转股；逐日 NAV 同时由执行矩阵和账本独立计算，差异超过 `1e-6` 即中止。
现金红利采用显式保守政策 `next_session_after_payment`，即发行人发放日后的
下一交易日才可再投资，不声称券商已在发放日开盘前入账。卖出按 FIFO lot
和持有期限补扣红利税；送转 lot 再遇后续权益或零碎股规则不明时仍显式阻断。

同信号回放要求封存 `backtest_signals.csv`、执行上下文及辅助文件逐文件
SHA256 一致，发行人条款文件也进入运行身份并在运行前后复核。归档审计不再把
原价成交误送进 QFQ 整手审计，而是核对逐日账本恒等式、NAV 和真实开盘参考价。
14 项快照测试与 12 项账本／执行回归均通过。

`raw_wealth_bridge_precision_split_20261101.csv` 将 21 条事件的两日财富差

### 2026-11-04 接线复核：限售送转股重复扣减预算

### 科创板申报数量与实盘共用规则（研究臂）

架构复核发现旧回测所有买入均按 100 股取整，实盘出单却对 688/689
