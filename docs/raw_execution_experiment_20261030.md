# 裸价成交回放：数据契约与实验门槛

现行向量化回测在 `strategy/bt_execution.py::_vectorized_backtest` 中把
自算 QFQ 开/收盘价用于股数取整、现金、持仓市值和收益。对应的实盘
下单读取裸价。2026-10-28 截止封存样本有 387 笔买入；按相同名义
金额换算成裸价整百股，301 笔股数不同，66 笔加仓金额低于一手裸价。
这只是成交模型的可行性诊断，不能把名义金额差直接加减到原回测净值。

实验须保持同一份已封存信号/选股决定，另外构造独立的裸价执行与估值
分支。开盘按裸价确定交易股数，保留现金不足、涨跌停、T+1、停牌、
最小交易单位和既有滑点/费用约束，收盘按裸价估值；股权登记日收盘
的真实持仓决定权益归属，除权日处理股份变化，现金红利在**明确的
到账日**成为可再投资现金，提前只记应收。组合权重或信号若依赖现有
QFQ 成交反馈，需在两臂中按各自真实模拟净值重新计算，不能在
不同现金/股数状态下复用另一臂的成交记录。

本地 `events_table.pkl` 只有 `ex_date, s, D, mult, src`，没有现金
发放日、新股可流通日及税费记账；`corporate_actions.pkl` 同样只有
`code, ex_date, s, D`。先对本次持仓跨越的 21 次事件回查公司实施
公告，提取股权登记日、除权日、红利到账日、送转股份可交易日及
差异化分配条款，记录出处与事件表内容哈希；缺任何关键字段的持仓
事件都不得静默假设当天到账。21 次跨事件中 3 次涉及送转，当前
21 条事件表 `s,D` 均非缺失。

当前本地事件表不含红利到账日，不能把 `ex_date` 字段假定为可用现金日；
实施公告中的具体日期和差异化条款须独立核验并随实验封存。

先以现金分红、送转、无公司行为三只股票构造可手工对账的回放样例，
检验除权日前后 `现金 + 应收 + 裸股数 × 裸价` 与 QFQ 价格财富变化
的关系；再上全池同信号的成本净值成对实验，输出逐日权益、买卖差异、
真实整手不可成交次数、1/3/5 日胜率、2026 年回撤和完整年度指标。
税费及同日到账无法证实前不得用该分支声称“实盘收益已经证明提高”。
