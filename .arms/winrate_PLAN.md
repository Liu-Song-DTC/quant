# 选股胜率优化计划 (2026-10-22 用户裁定)

> 用户: "调优方向终点放在如何提高选股胜率上"。
> 用户(同日追加): "胜率高，调仓快，拉升高，才是致胜的法宝，资金利用率才会高，收益才会高"。
> ⇒ 复合目标: **胜率↑ + 周转/调仓速度↑ + 拉升幅度↑ + 资金利用率↑**, 收益是结果.
> 本文件只做胜率轴; 已闭合的收益轴不再重开, 但**已闭合臂的胜率列要重新判读**.

## 0. 指标定义 (先定口径, 防止"胜率"被交易次数稀释)

| 指标 | 定义 | 当前基线 |
|---|---|---|
| 已实现交易胜率 tW | `trade_realized.ret > 0` 占比 | **52.85%** (246笔) |
| 信号层 5日胜率 w5 | 选中股: 次日开盘入场 → +5日收盘 > 0 | 43.93%* / 逐笔 **42.5%** |
| 信号层 20日胜率 w20 | 同上 → +20日收盘 > 0 | 58.57%* / 逐笔 **53.9%** |
| 月度胜率 mW | 月收益 > 0 的月份占比 | 55.71% (39/70) |
| 年度胜率 yW | 年收益 > 0 的年份占比 | 6/6 |

*注意: 上面的 w5/w20 来自 `rk_1022_analysis.py`, 其口径是**日收益**的前瞻胜率(所有交易日),
不是"选中股前瞻收益>0"的胜率. 本计划先重算**逐笔前瞻胜率**(选中股, 次日开盘入场),
作为选股层的干净口径 — 这是"选股胜率"最直接的度量.

**样本量纪律**: 246 笔 ⇒ 单组 50 笔的胜率 SE≈7pp; 前瞻胜率用全部入选 (~247) 仍只有
±3pp 精度. 任何 <5pp 的差异不做结论; 报告 Wilson 95% CI, 并做配对 McNemar.

## 1. 诊断先行 (不改代码/不跑回测)

数据: `portfolio_selections.csv.base_tr1022` (247行) + `trade_realized.csv.base_tr1022`
(246笔) + `backtest_signals.csv.pre_w730_1022` (3.25GB 生产信号备份) + qfq 日线.

### D1 已实现交易胜率剖面
按以下维度分组, 每组报 n / 胜率 / 均收益 / PF:
- 入选分数 score 五分位 (关键: 分数是否单调预测胜率?)
- 同一调仓日内 score 名次 (1/2/3 名)
- 权重 weight 五分位
- 年份 / 季度
- 入场时 regime (NORM/FAST/BEAR)
- 持有天数 (注意: 出场规则内生, 只作描述)

### D2 逐笔前瞻胜率 (选股层的干净口径)
对每笔入选, 用**次日开盘**入场, 计算 +1/+3/+5/+10/+20 日收盘胜率与均值:
- 按 score 五分位 → 分数单调性
- 按 ml_score 五分位 → ML 的增量区分度 (blend_weight=0.4 下 ML 是否真在选股?)
- 按 signal_level / bi_buy_point 计数 / chan_buy_point → 买点源
- 按 industry → 行业集中度 (只报 n≥15 的行业)
- 按 entry gap (次日开盘/信号日收盘−1) 分组
- 按 20日波动率 / 60日动量 分组 (入场时点特征)

### D3 时间稳定性
把 D1/D2 中效应最大的 3-5 个维度, 按 2021-2023 / 2024-2026 两段分别重算,
要求两段**同号**才进入候选. 防止全样本数据挖掘.

### D4 已闭合轴的胜率复查 (不重跑)
读 `.arms/ledger.csv` + 历史臂日志, 找已跑过但只在"收益"判据下被否的臂:
- bp_confirm_min=4 (NAV −46%, 胜率?)
- 买点源消融 (S1/S2/S3/S4)
- 其他带胜率列的臂
若某轴在胜率上显著为正、且 NAV 护栏内, 用**胜率优先判据**重新评估 (不必重跑).

## 2. 候选干预面 (诊断后再定, 先列可能)

1. **分数/ML 门槛**: 只取 score 或 ml_score 前 X% (需信号重生成或组合层过滤).
2. **确认数**: bp_confirm_min 3→4 (已有臂, 复查胜率).
3. **买点源**: 要求某类源 (已有源级臂).
4. **名次/宽度**: 每次调仓只取 top-1/top-2 (mp3→mp2 会改变收益, 但胜率?)
5. **时点**: 高开不追 (gap 过滤已闭: 无信号), 低开/回踩入场 (tranche 已闭).
6. **行业/regime 条件**: 只在胜率高的 regime/行业开仓 (需 PIT, #352 暂缓).
7. **持有期/出场**: 只影响已实现胜率, 不是选股层; 优先级最低.

## 3. 预注册判据 (胜率优先版)

任何候选臂 (配对, 同一信号集):
- (W1) **主判据**: 逐笔 5日/20日前瞻胜率 + 已实现交易胜率, 至少两个口径同向,
  且 McNemar 配对 p<0.05 (只算不一致样本).
- (W2) 效应在两段时间 (2021-23 / 2024-26) 同号, 且每段 n≥60.
- (W3) **收益护栏**: ΔNAV > −50k (相对 984,331), Sharpe 不低于基线−0.03,
  MDD 不恶化超过 2pp. 若胜率提升 ≥8pp, 允许 ΔNAV 放宽到 −100k (需明示).
- (W4) 胜率提升不能靠**删掉亏损样本后样本量骤降**来制造: 保留笔数 ≥ 基线的 60%
  (即 ≥148 笔), 或明确报告"高胜率低覆盖"版本.
- (W5) ex-top: 剥离最大盈利单笔后, 胜率提升仍存在 (胜率是计数指标, 单笔影响有限,
  但需确认不是"只赢了一笔大亏的邻域").
- (W6) 分年: 6 年中至少 4 年胜率不劣化; 报告全表.

**为什么 ah1 单独砍反而亏**: 砍掉 AH 后空出的槽位被下一名 (常是第3名) 填上,
坏桶换坏桶 ⇒ tW +3.2pp 但 NAV −32.6k / Sharpe 1.2572 (W3 不过)。

ex-top +5.1pp, 但相对 new2 只多 +0.65pp tW / +0.2pp w20, 代价 **−70k NAV / −0.084 Sharpe**。
⇒ **AH 不进入采纳包**: 增量 <1pp 属噪声, 且 ah1 单独不过护栏; 记为"若纯胜率优先"的备选。
(注意 new2ah 的 Sharpe 1.3039 仍过 W3 下限 1.2905, MDD −19.38 也在护栏内。)

### 7.6 W1 口径修正: 组合型过滤器必须用**日级簇 bootstrap**, McNemar 无检验力

new2 与基线在共有 (date,code) 上的前瞻/已实现结果**逐位相同** (臂独赢=基独赢=0),
McNemar 只算不一致样本 ⇒ p≡1.000, 对"构成型"过滤器**结构上无检验力**。
正确口径: 以**调仓日为簇**重采样 (156 个日期, 5000 次), 对每个周期的胜率差取 CI。
结果 (new2 − base, pp):

| 周期 | 观测Δ | 簇 bootstrap 95% CI | P(Δ>0) |
|---|---|---|---|
| 已实现 tW | +4.51 | [+1.38, +7.69] | 0.998 |
| w1 | +3.25 | [+0.73, +5.69] | 0.994 |
| w3 | +3.16 | [+0.73, +5.45] | 0.995 |

### 8.5 方法论 (本轮新增, 必须常驻)

1. **池级边际 ≠ 选择边际**: 任何"按特征跳过/加成"的规则, 必须在逐日重选前2名的
   反事实里验证; 池级三分位只能用来生成假设。动量、加成、AH 名级都栽在这里。
2. **先分日型, 再谈个股**: 同一特征在池级显著, 可能只是标记了不同的调仓日
   (AH、target_exposure、k=1/2)。日级簇 bootstrap 只能处理相关性, 不能替代分层;
   必须按 k / AH / te 分层看。
3. **构成型臂的判据**: 日级簇 bootstrap 为主; McNemar 只在"同一标的结果改变"时有意义。
