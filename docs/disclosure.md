## 3. 重述披露流程 (navlaw 两档)

净值/数据历史被改写时 (navlaw --strict rc=2), 只允许两种显式放行, 原因进当日日志:

```
NAVLAW_OVERRIDE="<原因>"    # 今日放行, 明日继续报 — 用于: 已定位待修, 不带病出单披露
NAVLAW_REBASELINE="<原因>"  # 重锚: 立新基线不再复报 — 用于: 供应商重述/已登记修复
```

**放行后 24h 内**: ① 在本文件 §4 追加一行 ② 重跑 `python tools/data_state_ledger.py`
③ 若新锚: anchor.json 重铸 (嵌 prev_anchor) + `.arms/ledger.csv` 登记。
