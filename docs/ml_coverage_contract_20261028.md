# ML 预测覆盖与历史准入约定（2026-10-28）

生产入口 `strategy/run_daily_live.sh` 先运行 `bt_execution.py` 重算信号，再据同一批信号出单。`strategy/core/live_init.py` 的单股模型路径并非该入口，不应拿它的回退行为代替出单验证。

此前 `SignalEngine._vectorized_score_assembly` 的缓存查找把 `valid`（因子有效性）覆盖为 `idx >= 0`（当日之前能查到该股预测），导致准入规则随 ML 缓存覆盖发生变化。修复后分开记录因子有效性与有限预测可用性，用显式 `ml.coverage_policy: require_prediction` 取交集；不把浮点预测值恰好为 0 判作缺失，缓存中未来才出现的股票不会提前入选。配置中明确启用此口径，不依赖代码偶然的同名变量。没有可用预测时不新增买入信号，风控卖出仍须依靠组合执行层；真实券商回报需单独核对。

封存全量回测：2021-01-04—2026-10-23；最终权益 882,519.85 元，Sharpe 1.2255，最大回撤 21.3615%；与旧封存基线的逐日净值、2343 条成交回报、组合选择、已平仓收益四份文件均逐字节相同。封存预测文件包含 3,243,907 行、702 个预测日、5,256 只股票，预测日期截至 2026-10-22。161 条入选记录均能找到同股不晚于信号日的预测；仅 88 条预测日恰好等于信号日。其余是向前取最近一次预测，日历间隔中位数 0 天、95 分位 5 天、最长 11 天；长间隔均落在节假日。该检验没有证明历史模型训练时间可用性，历史模型和输入版本仍需独立审计。

只修掉同名变量遮蔽而不补回历史 ML 准入条件的独立全量对照，权益为 555,363.73 元、回撤 26.74%。这说明准入规则对历史收益重要，但并非条件本身产生了新 alpha。研究未来不同覆盖策略时必须单独配对试验；不能将 `require_prediction` 重现原表现误写成优化成功。
