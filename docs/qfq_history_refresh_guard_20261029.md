# QFQ 旧行稳定性：刷新前逐行门禁

生产 `data/refresh_fetch.sh` 建立新的 QFQ 目录后，先用 `data/guard_qfq_history.py` 和仍在使用的生产目录比较。所有已有证券的 CSV 表头和全部旧日期行必须维持历史口径；新日期行和新上市证券允许追加。发现旧价格、量额、交易日、列结构或其他未授权字段改变时，保留候选目录作取证，**拒绝换入生产目录**，不自动宣称数据供应商更正后的回测收益仍是原基线。

换手率、振幅、涨跌幅都是现有量价因子的输入，不能把旧日期 0.01 的供应商回修当作无关噪声直接忽略。**只有**旧行的差异全部限于 `turnover_rate`、`amplitude`、`change_percent`、`change_amount`，且 OHLC、量额和日期等核心字段逐字节一致时，门禁才在候选目录原子写回**旧发布值**，只让新交易日接受新观测；JSON 报告保留改值前后的旧行、新行、日期、字段和发生只数。若有任何其他旧值改变，先不修补任何候选文件，直接阻断并排查。合法的历史修订应以独立数据版本配对回测，再明确决定是否重置基线。

只读探针（不得对生产目录使用 `--preserve-auxiliary`）：

```bash
.venv/bin/python -B data/guard_qfq_history.py \
  --old data/stock_data/.bt_prev --new data/stock_data/backtrader_data \
  --out /tmp/quant_qfq_prev_current_20261029.json
```

此门禁不替代 `events_table.pkl` 的发行人公告条款核对、原始价持仓及股息入账，也不验证基本面、概念、另类数据的历史发布时间；这些来源的历史漂移仍须单独审计。

2026-10-29 的只读实测：比较 `.bt_prev` 与当前 `backtrader_data` 的 5,353 只证券、11,035,681 条旧行，26 只证券共 104 条旧行被回修，分别涉及换手率 98 格、涨跌幅 2 格、振幅 5 格（同一行可涉及多格）；未发现被改写的旧 OHLC、量额或日期。此次探针不修改生产数据，也不能证明下一次刷新不会出现新的核心数据修订。刷新链路会在候选目录执行修补及阻断；未在此实验里实际下载新数据或运行全量策略回测。
