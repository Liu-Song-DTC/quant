# 生产前复权事件日全池核对（2026-10-28）

使用`.review_runs/data_catalog_quarantine_20261027/data`封存快照；审计脚本`strategy/analysis/audit_qfq_events.py`仅读，不重建或修改任何K线、事件与锚文件。审计读取生产`refresh_all.sh`传给`rebuild_table_qfq.py --events`的**融合**`events_table.pkl`，而非原始`corporate_actions.pkl`；按同股票裸收盘和有效事件乘数独立计算除权日收益，再与回测收盘价比对。考虑输出复权价两位小数舍入，逐事件检查数学误差上界；日历错位和非法输入单独报错。测试覆盖送转+现金分红、融合乘数优先与人为改坏复权价。

完整报告：`.review_runs/qfq_event_audit_20261028/report.json`。核对5,350只股票、37,326个事件日，超过两位小数舍入上界的记录**0**；剩余3份无`none.csv`文件为`399006`、`sh000001`、`sh000852`三个指数，正常走指数单独分支。2021年起23,677个事件日的单日收益绝对误差中位数0.0152个百分点，95分位0.0979个百分点、最大0.5800个百分点；**没有**前日复权价不足1元或误差超过1个百分点的事件。全历史最大误差4.5751个百分点，出现在1996年`600705`前日复权价仅0.11元，两位小数舍入上界允许这一误差；早期价格不可作为精细收益标签的证据。

同时核对10,985,136个**非事件日**（2021年起6,834,735个）：裸价收益与前复权价收益超过舍入边界的记录为0。2021年起有2,991条非事件日记录的前日复权价不足1元、35条单日收益舍入差超过1个百分点，最大差2.0262个百分点；161条真实入选记录的信号日复权收盘价最低2.13元、没有低于1元的入选。低价舍入仍可能影响训练样本和连续因子，若实验将精度从两位提升到更多位，必须封存双臂重训并检查选股/成本，不能直接改生产历史数据。

这一审计只能证明“当前封存裸价、复权价和所用事件表在收益上自洽”，无法证明事件表没有漏项、9条`src=frozen`反推固定事件真实正确、非事件日数据源本身没有被一起改写、或者历史绝对复权价等于实盘现金/股数记账。生产数据包括36,041条东财、1,282条新浪、14条现金修正、9条冻结事件。下一步审计原始公告与第三方事件覆盖，再独立测未复权成交价、分红到账和股数变化。深圳证券交易所[投资者问答](https://www.szse.cn/www/investor/knowledge/t20181017_555756.html)列示除权参考价公式及特殊情形；本审计的“财富收益”验算不能替代含配股认购价格和现金到账的实盘执行核验。
